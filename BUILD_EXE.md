# Как получить MarketScanner.exe через GitHub

GitHub бесплатно соберёт программу на своих серверах с Windows. Делать это нужно один раз. Потом, когда будете заменять файлы на новые версии, он сам пересоберёт `.exe`.

Время: около 15 минут. Всё делается в браузере на компьютере.

## 1. Создать аккаунт

1. Откройте https://github.com/signup.
2. Введите почту, придумайте пароль и имя пользователя, подтвердите почту кодом из письма.
3. На вопросы о плане выберите **Free**.

## 2. Создать репозиторий (папку для файлов программы)

1. Справа вверху нажмите **«+» → New repository**.
2. Repository name: `market-scanner`.
3. Выберите **Private**, чтобы файлы видели только вы.
4. Поставьте галочку **Add a README file**.
5. Нажмите **Create repository**.

## 3. Загрузить файлы

1. Распакуйте архив `market_scanner_app.zip` на компьютере.
2. В репозитории нажмите **Add file → Upload files**.
3. Перетащите в окно браузера **всё содержимое** распакованной папки, включая папку `.github`. Если её не видно, включите в Проводнике «Вид → Показать → Скрытые элементы».
4. Внизу нажмите **Commit changes**.

**Проверка:** в репозитории должна появиться папка `.github/workflows` с файлом `build.yml`.

Если папка `.github` не загрузилась, создайте этот файл вручную:
1. Нажмите **Add file → Create new file**.
2. В поле имени впишите `.github/workflows/build.yml`. Косые черты сами превратятся в папки.
3. Скопируйте в поле ниже содержимое файла `build.yml` из архива.
4. Нажмите **Commit changes**.

## 4. Дождаться сборки (5–10 минут)

1. Откройте вкладку **Actions**: там идёт «Сборка MarketScanner.exe». Жёлтый кружок — идёт сборка, зелёная галочка — готово.
2. Сборка сама проверяет программу: открывает окно и прогоняет сканер на учебных данных.
3. Если появился красный крестик, откройте сборку, нажмите на шаг с ошибкой, скопируйте текст и пришлите мне.

## 5. Скачать программу

1. На главной странице репозитория справа найдите **Releases** и откройте последний выпуск «MarketScanner, сборка N».
2. Скачайте `MarketScanner.exe`.
3. Создайте папку, например `C:\MarketScanner`, положите туда `MarketScanner.exe` и запустите.

Рядом с программой сами появятся `config.json` (настройки) и папка `scanner_data` (база истории, отчёты, память модели).

**Если Windows пишет «Система Windows защитила ваш компьютер»**, нажмите **Подробнее → Выполнить в любом случае**. Так бывает с любой программой без цифровой подписи.

**Если ругается антивирус**, добавьте папку `C:\MarketScanner` в исключения.

## Обновление

Когда я пришлю новую версию:
1. Загрузите изменённые файлы в репозиторий так же, через **Add file → Upload files**. Файлы с тем же именем заменятся.
2. Через несколько минут в **Releases** появится новая сборка.
3. Закройте программу (значок в трее → Выход), замените `MarketScanner.exe` на новый и запустите.

Настройки, база истории и обученная память при этом сохранятся.

## Важно

- `config.json` с вашими ключами Финама и Alpaca **не загружайте** в GitHub. Он хранится только на вашем компьютере, и файл `.gitignore` защищает его от случайной загрузки.
- Бесплатного лимита GitHub (2000 минут сборки в месяц для приватных репозиториев) хватит примерно на сотню сборок.
